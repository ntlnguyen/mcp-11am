# MCP server

This repo provides `good_day_or_bad_day(company, date)` and
`similar_stock(company, date)` through MCP Streamable HTTP at `/mcp` on port
8000. Implementation and tool descriptions are in `server.py`.

Create a Codespace; startup is automatic. Make port 8000 **Public** in the
Ports panel, and give the chatbot the forwarded HTTPS address plus `/mcp`.
No OpenAI key is needed. Keep the Codespace running for the exercise.
